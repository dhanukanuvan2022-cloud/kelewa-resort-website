KELEWA ECO RESORT WEBSITE DEMO

Files:
- index.html   Main website page
- styles.css   Responsive design and visual styling
- script.js    Mobile navigation, booking enquiry form, gallery lightbox, and reveal effects
- assets/      Optimized WebP versions of the supplied resort photos

HOW TO PREVIEW ON KALI LINUX
1. Extract the ZIP file.
2. Open a terminal inside the kelewa-resort-website folder.
3. Run: python3 -m http.server 8000
4. Open: http://127.0.0.1:8000

IMPORTANT BEFORE SELLING/PUBLISHING
- This is a front-end demo. Booking enquiries open WhatsApp; there is no database, admin dashboard, online payment, or automatic booking confirmation.
- Confirm the phone/WhatsApp number, exact address, room names, amenities, check-in/check-out times, rates, ratings and reviews with the resort owner.
- Only publish the resort's name and supplied photos after receiving permission from the owner.
- The external Google Fonts request requires internet; system serif/sans-serif fallbacks are included.
